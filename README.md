# 🗺️ TourisManager - Web Quản Lý & Hiển Thị Bản Đồ Du Lịch

Dự án ứng dụng Web ASP.NET Core MVC kết hợp với **Leaflet Maps API** để quản lý và hiển thị danh sách các điểm đến du lịch (Destinations) trực quan trên bản đồ tương tác.

---

## 🛠️ Công Nghệ Sử Dụng

- **Backend:** ASP.NET Core 8.0 / 9.0 (MVC & RESTful API)
- **Database:** SQL Server + Entity Framework Core (Code First)
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API, Async/Await)
- **Bản đồ:** Leaflet.js + Map Tiles (Google Maps, OpenStreetMap)

---

## 🚀 Hướng Dẫn Cài Đặt & Chạy Dự Án

### 1. Yêu cầu tiền đề (Prerequisites)
